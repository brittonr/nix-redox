    Wait for Ready before typing or running a command.

    Focus & paste. Click the terminal to type. On Linux, paste with Ctrl+Shift+V (Ctrl+V is literal-next). On a phone, the command editor below is easier. Guided actions temporarily own serial input so keystrokes cannot mix with a running command.

    Stop & reset. Stop terminates even an unresponsive VM. Reset cold-boots or restores the selected startup again, discarding all guest writes, profiles and build results; verified immutable downloads may be reused. Ctrl+C sends byte 0x03 when no text is selected, but this serial debug scheme is not a full POSIX TTY and does not generate SIGINT for guest programs.
