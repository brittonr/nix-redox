Live Redox in your browser

The real x86_64 Redox kernel and Snix run locally under QEMU-WASM. No remote VM. Guest networking is disabled.

Watch the recorded demo instead. Browser support and resource requirements are experimental until the release's real-guest smoke evidence passes.

Redox guest

Stopped. Start the VM to load its immutable artifacts.

Click the terminal to type or edit command lines; on Linux, paste with Ctrl+Shift+V (Ctrl+V is literal-next). Ctrl+C sends byte 0x03 when no text is selected; the serial debug scheme is not a full POSIX TTY and does not generate SIGINT for guest programs. Stop always terminates an unresponsive VM. Reset discards all guest writes, profiles and build results; verified immutable downloads may be reused.

Run real guest commands

These actions use the same guest serial input path as typing. Expressions and command text are encoded as data, never substituted into shell syntax.
