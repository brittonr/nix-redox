Help
  • Click the console to type. Paste with Ctrl+Shift+V; Ctrl+V is literal-next.
  • On a phone, use the Shell tool.
  • While a tool runs, console input is paused.
  • Stop ends the VM at any time. Reset starts a fresh guest, discarding all changes.
  • Ctrl+C sends byte 0x03, but the serial console is not a full TTY, so guest programs get no SIGINT.
