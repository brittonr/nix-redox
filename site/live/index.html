nix-redox / browser-local workbench

Live Redox lab

Run the real Redox kernel and Snix locally in this tab—no remote VM or Nix installation. Press Boot and wait for Ready; first startup can take several minutes. Experimental desktop-browser support, no guest networking, and guest writes are discarded on reset.

The browser emulator is adapted from TryNix by Farid Zakaria (MIT license), built on Kohei Tokunaga's QEMU-WASM.

Terminal input, paste & session help

Focus & paste. Click the console to type. On Linux, paste with Ctrl+Shift+V (Ctrl+V is literal-next). On a phone, use the Shell tool below the console. Guest actions temporarily own serial input so keystrokes cannot mix with a running command.

Stop & reset. Stop terminates even an unresponsive VM. Reset cold-boots or restores the selected startup again, discarding all guest writes, profiles and build results; verified immutable downloads may be reused. Ctrl+C sends byte 0x03 when no text is selected, but this serial debug scheme is not a full POSIX TTY and does not generate SIGINT for guest programs.

    About this lab & getting started
    1. 01
      Boot the guest
      Immutable VM assets are downloaded and verified. First boot can take several minutes.
    2. 02
      Wait for Ready
      Boot text is not a ready shell. Commands unlock only after the guest reports it is ready.
    3. 03
      Work in one session
      Use the console or the Shell, Nix and Packages tools. The WASM evaluator is independent; Run in Redox explicitly uses this guest.
    Experimental browser support and resource requirements depend on this release's real-guest smoke evidence. Prefer a desktop browser with memory to spare; keep this tab open while the VM runs.
