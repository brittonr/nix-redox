## Notes

- PCIe devices ONLY visible with 12V DC power supply (not USB-C alone)
- Carrier Lite docs confirm: "PCIe slot only available with 12V supply via DC 5.5x2.5mm"
- NIC is RTL8111/8168 (Realtek 10ec:8168) — use rtl8168d driver in Redox
- NVMe is c0a9:5426 — need to check if nvmed supports this controller
- USB-C only: PCIe buses 01/02 are empty, no NIC, no NVMe
- 12V DC only: HDMI output stops working (JetKVM shows no signal), serial also stops
- May need BOTH USB-C + 12V DC simultaneously for full functionality
- No legacy 16550 UART (dmesg shows nothing for uart)
- /proc/ioports shows "0000-0000 : serial" (zero-length range)
- Two xHCI controllers: 00:0d.0 (Processor USB 3.2) and 00:14.0 (PCH USB 3.2 Gen 2x1)
- eMMC controller at 00:1a.0
- HDA audio at 00:1f.3 [8086:54c8]
